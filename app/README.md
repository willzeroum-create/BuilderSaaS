# app/

Aqui mora o software da sua empresa.

Enquanto o `/app` não roda pela primeira vez, esta pasta fica vazia.
Depois, ela passa a ter o sistema, e este arquivo é substituído por um
README de verdade explicando:

- como rodar o sistema no seu computador
- como publicar uma alteração
- onde ficam as configurações
- o que fazer quando der erro

Esse README é escrito pensando em **outra pessoa**, não em você. Se quem
montou sair da empresa, é ele que salva a operação.
