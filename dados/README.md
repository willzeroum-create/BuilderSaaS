# dados/

Aqui ficam os arquivos de origem: planilhas, exports, PDFs, bases antigas.

**Nada aqui é modificado.** O `/planilha` lê, mas nunca sobrescreve. A
planilha original é o seu backup enquanto a migração acontece.

O conteúdo desta pasta **não vai pro repositório** (está no `.gitignore`),
porque normalmente contém dado real de cliente. Só este README é versionado.
