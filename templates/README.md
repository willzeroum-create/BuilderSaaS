# templates/

Modelos reaproveitáveis que o sistema usa e cria ao longo do trabalho.

Começa vazia de propósito. Conforme a empresa vai construindo, aqui ficam
as peças que se repetem:

- **modelos de skill** — pra criar comandos novos no padrão da casa
- **modelos de tela** — o padrão visual e de comportamento do sistema
- **modelos de documento** — proposta, processo, relatório
- **modelos de e-mail** — as mensagens que o sistema dispara

Quando você pedir algo pela segunda vez, o BuilderSaaS oferece transformar
aquilo num modelo e guarda aqui. A partir daí, a terceira vez é imediata.
